# Xilulu Team Console — 对话式企业管理平台

> **不是后台管理系统，是你的企业副驾驶。**

## 🎯 一句话定义

传统后台管理 = **表格 + 表单 + 侧边栏菜单**
Xilulu Team Console = **对话 + 画布 + 意图理解**

我们要做的不是一个「让管理员在密密麻麻的表格里翻找数据」的系统，
而是一个「你说一句话，事情就办完了」的**智能管理界面**。

---

## 💡 核心理念

### 1. Command-First，不是 Menu-First

传统 Admin：用户从侧边栏菜单 → 点进子菜单 → 找到页面 → 填写表单 → 提交。
5 步，每一步都在消耗认知。

**我们的方式**：

```
┌──────────────────────────────────────────────┐
│                                              │
│   ⌘K  "把张三从市场部调到产品部"              │
│                                              │
│   🧠 识别意图: 员工调岗                       │
│   📋 自动生成操作预览卡片:                     │
│   ┌────────────────────────────────────────┐ │
│   │  👤 张三 (工号: EMP-0042)               │ │
│   │  ← 市场部  →  产品部                    │ │
│   │  ⚠️ 主部门将变更                         │ │
│   │                                        │ │
│   │  [ 确认执行 ]  [ 编辑细节 ]  [ 取消 ]    │ │
│   └────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

**不再有菜单导航**。所有操作都可以通过**全局命令面板**（⌘K / Ctrl+K）触发。
输入自然语言，系统理解意图，生成操作预览，一键执行。

### 2. 对话式工作流（Conversational Workflow）

不是聊天机器人，而是**操作上下文**。每一次管理操作都是一段「对话」：

```
你：创建一个新部门叫"AI实验室"，放在技术中心下面
系统：
  ┌─ 操作预览 ─────────────────────────────┐
  │  📂 新建部门: AI实验室                    │
  │  📍 上级: 技术中心                        │
  │  🏢 所属组织: Xilulu Inc                  │
  │                                          │
  │  需要指定负责人吗？                        │
  └──────────────────────────────────────────┘

你：负责人是李四
系统：
  ┌─ 操作确认 ─────────────────────────────┐
  │  ✅ 已创建部门: AI实验室                   │
  │  👤 负责人: 李四                           │
  │  📊 当前成员: 0 人                         │
  │                                          │
  │  要批量导入成员吗？                        │
  └──────────────────────────────────────────┘
```

系统会**主动追问缺失信息**，引导你完成完整操作，而不是让你面对一堆必填字段。

### 3. 空间画布（Spatial Canvas），不是表格地狱

部门结构不用表格展示，用**可交互的力导向图**：

```
          ┌──────────┐
          │  CEO     │
          └─────┬────┘
       ┌────────┼────────┐
  ┌────▼───┐ ┌──▼───┐ ┌──▼────┐
  │ 技术中心│ │市场部 │ │ 财务部 │
  └────┬───┘ └──────┘ └───────┘
  ┌────▼───┐
  │AI实验室│  ← 刚创建的，带发光呼吸动画
  └────────┘
```

- **拖拽调整**组织结构 → 自动生成变更审批
- **点击节点**展开成员气泡 → 直接发起操作
- **缩放**查看全局组织拓扑 → 数据热力图叠加

### 4. 卡片流（Card Stream），不是分页列表

所有实体都以**智能卡片**呈现，不是表格行。

```
┌─ 员工卡片 ──────────────────────────────┐
│ 👤                                       │
│ 张三                                     │
│ 产品经理 · 产品部                          │
│ ───────────────────────────────────       │
│ 📱 138****5678  📧 zhang@xilulu.com       │
│ 📅 入职 2024.03  🟢 在职                  │
│                                          │
│ ┌──────┐ ┌──────┐ ┌────────┐             │
│ │ 调岗  │ │ 详情  │ │ 发消息  │            │
│ └──────┘ └──────┘ └────────┘             │
└──────────────────────────────────────────┘
```

卡片可以：
- **堆叠**成看板视图（按部门/状态分组）
- **展开**成详情面板（右侧滑出，不跳转页面）
- **拖拽**到其他区域（调部门、改岗位）
- **批量选中**后通过命令面板执行批量操作

└────────────────────────┬─────────────────────────┘
                         │
┌────────────────────────▼─────────────────────────┐

### 四大核心场景

#### 场景 1：Cockpit（驾驶舱）— 首页

不是仪表盘上堆一堆图表，而是一个**实时跳动的组织心跳**：

```
┌──────────────────────────────────────────────────┐
│ Good evening, fangbc                              │
│                                                    │
│ 🫀 Organization Pulse                              │
│ ┌──────────────────────────────────────────────┐  │
│ │  ●●●●●●●●●●  368 人在职   △2 本周           │  │
│ │  活力指数 87%  ▲ 3.2% vs 上周                │  │
│ └──────────────────────────────────────────────┘  │
│                                                    │
│ 📋 待处理                                          │
│ ┌────────────────────────────────────────────┐    │
│ │ ⏳ 3 位新员工等待部门分配                     │    │
│ │ 📝 产品部申请增设"体验设计组"                  │    │
│ │ 🔄 2 位员工调岗申请待审批                     │    │
│ └────────────────────────────────────────────┘    │
│                                                    │
│ ⌘K  试试说点什么...                                │
└──────────────────────────────────────────────────┘
```

#### 场景 2：Atlas（组织地图）— 可视化

组织不是表格，是一张**活地图**：
- **拓扑视图**：力导向图展示组织全貌，节点大小 = 人数，连线粗细 = 协作频率
- **热力视图**：哪些部门在扩张，哪些在收缩
- **时间轴**：滑动查看组织在过去 N 个月的结构变迁

#### 场景 3：People（人员流）— 通讯录 + 管理

不是表格列表，是**人脸墙 + 卡片流**：
- 搜索优先，滚动浏览为辅
- 卡片视图 / 看板视图 / 紧凑列表三种模式
- 所有操作都在**右侧滑出面板**内完成，不离开当前页

#### 场景 4：Flow（工作流引擎）— 审批 + 自动化

可视化的工作流编辑器：
- 拖拽式节点编排（调岗 → 审批 → 通知 → 权限变更）
- 对话式创建：「帮我设置一个规则：离职超过 30 天自动归档」

## 🎨 设计语言

### 整体风格：「深空」设计系统

不走 Ant Design / Element 的「企业灰」路线，走**深空科技感**：

| 维度 | 传统 Admin | Xilulu Console |
|------|-----------|----------------|
| 背景 | #f5f5f5 浅灰 | #0a0e1a 深空蓝 + 微星空纹理 |
| 主色 | #1890ff 蓝 | 渐变极光色 (紫→青→蓝) |
| 卡片 | 白色实底 | 毛玻璃 (backdrop-filter: blur) |
| 图标 | 线性 outline | 发光霓虹 + 微动画 |
| 字体 | 系统默认 | Inter / 思源黑体 |
| 交互 | 点击→跳转 | 滑出面板 + 命令面板 |
| 动画 | 几乎无 | 弹簧物理 + 粒子效果 |

### 动画哲学

- **进入**：元素从下方弹入，带弹簧过冲
- **消失**：淡出 + 微缩放
- **切换**：形变过渡（morph transition），不是硬切
- **加载**：骨骼屏 + 发光脉冲
- **操作反馈**：涟漪扩散 + 微震动

### 命令面板 UI

全局命令面板是整个系统的灵魂：

```
┌───────────────────────────────────────────────────────┐
│ ⌘                                                      │

## 🧩 技术方案

### 前端

| 技术 | 选型 | 理由 |
|------|------|------|
| 框架 | Dioxus 0.7 (Web) | Rust 全栈，与 packages/web 一致 |
| 路由 | dioxus-router | 内置 |
| 状态管理 | Signal + Context | Dioxus 原生 |
| 样式 | TailwindCSS + 自定义 CSS | 已有 tailwind 基建 |
| HTTP 客户端 | reqwest (WASM) / gloo-net | 调用 ms-team API |
| 动画 | CSS transitions + requestAnimationFrame | 弹簧物理需手写 |
| 图可视化 | 自研 SVG Canvas | 力导向图引擎 |
| 命令面板 | 自研组件 | 核心差异化 |

### 后端对接

```
xilulu-app-dioxus/packages/web
          │

          ▼
    ms-team (Rust Axum)

    ├── /api/v1/team/positions/**
    ├── /api/v1/team/contacts/**

## 📐 分阶段路线图

### Phase 1 — 骨架 + 命令面板（2 周）

搭建核心差异化：全局命令面板 + 深空设计系统

- [ ] 深空主题 CSS 设计系统
- [ ] 全局 ⌘K 命令面板组件
- [ ] 路由 + 布局（顶部极简导航 + 主内容区）
- [ ] ms-team API 客户端封装
- [ ] 命令注册中心（硬编码命令列表）

**里程碑**：能通过 ⌘K 搜索并跳转到各页面

### Phase 2 — Cockpit + People（3 周）

核心视图落地

- [ ] Cockpit 驾驶舱首页
  - 组织 Pulse 动画
  - 待处理卡片流
  - 最近操作时间线
- [ ] People 人员流
  - 员工卡片组件
  - 卡片网格 + 搜索
  - 滑出详情面板
  - 内联编辑（调部门/改信息）

**里程碑**：可以浏览员工、查看详情、通过命令面板搜索人员

### Phase 3 — Atlas 组织地图（3 周）

空间化的组织视图

- [ ] SVG 力导向图引擎
- [ ] 部门节点交互（展开/收起/点击）
- [ ] 拖拽调整部门结构 → 生成变更预览
- [ ] 缩放 + 平移 + 自适应布局
- [ ] 热力图叠加（人数/增长率）

**里程碑**：组织结构的空间化浏览与交互式编辑

### Phase 4 — 对话式操作（3 周）

命令面板升级为对话引擎

- [ ] 自然语言意图解析（前端规则引擎，非 LLM 依赖）
- [ ] 多轮对话式操作（缺失参数自动追问）
- [ ] 操作预览卡片（确认/编辑/取消）
- [ ] 批量操作支持
- [ ] 操作历史 + 撤销

**里程碑**：「把张三从市场部调到产品部」一句话完成

### Phase 5 — Flow 工作流 + 打磨（3 周）

- [ ] 可视化工作流编辑器
- [ ] 审批流程
- [ ] 微动画全面打磨
- [ ] 响应式适配
- [ ] 性能优化

## ⚡ 不做什么

明确边界，让产品有灵魂：

| ❌ 不做 | ✅ 替代方案 |
|--------|-----------|
| 传统侧边栏菜单 | ⌘K 命令面板 + 顶部极简导航 |
| 分页表格 | 无限滚动卡片流 |
| 页面跳转 | 滑出面板 + 内联编辑 |
| 密密麻麻的表单 | 对话式引导 + 操作预览 |
| Chart.js 图表堆砌 | 数据融入交互（心跳、热力图） |
| 全功能权限管理 | Phase 1 先做浏览 + 基础操作 |
| LLM 依赖 | 前端规则引擎解析意图（离线可用） |
